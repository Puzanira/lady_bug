# Форма — LadyBugHitTheRoad

Обновлено по состоянию проекта на **август 2026**. Физический жест и датчик
спроектированы; на клавиатуре — полная симуляция. Прошивка на 2 датчика
(CombinedBoard или GestureSensors) и приём в Unity написаны и проверены на
реальном железе — см. [`hardware-wiring.md`](hardware-wiring.md).

**Рабочее название:** LadyBug Hit The Road

**Тема:** Божья коровка (или две — локальный кооператив) бежит по
многополосной дороге в перспективу (полос **1–7**, выбирается в меню, по
умолчанию 3). Собирать «хорошие» объекты, уворачиваться от «плохих», вдвоём —
совместные трюки.

**Место в мега-проекте:** это игра 1 из 7 на общем аркадном автомате;
остальные 6 слотов пока пустые (`docs/technical-details.md`, раздел 3.0).

**Одна фраза игры:** Управляй божьей коровкой (одна или вдвоём) на
бесконечной дороге, которая сама разгоняется: собирай цветы и сердечки,
объезжай препятствия, ныряй под арки, выполняй трюки — **проезжай 10 км**
быстрее всех (`WinSequence.WinSegmentDistanceKm`).

**Игрок управляет:** полоса (влево/вправо), прыжок, присед. Газ/тормоз
**убраны** — дорога разгоняется сама; прыжок = **взмах** обеими руками
(ритмичное движение, не статичная поза «обе вверх»).

**Вдвоём — трюки (7 штук):** АРКА (один приседает, другой перепрыгивает),
КОЛЬЦО (одновременный обмен полосами — один по воздуху, другой понизу),
ЧЕХАРДА (верхний сходит со стопки, нижний одним прыжком перекрывает обе
оставшиеся полосы), СИНХРОН (стоя стопкой, оба дважды жмут одно направление и
проезжают 3 полосы от края до края), БОЛЬШОЕ КОЛЬЦО (петля туда-обратно через
3 полосы: туда по земле, обратно по воздуху), БЕСКОНЕЧНОСТЬ (восьмёрка по трём
полосам), ЗАВИСАНИЕ (оба в воздухе 5 секунд подряд, не касаясь дороги).
Разбор условий и детекторов — `docs/technical-details.md`, раздел «Трюки».

**Что мешает:** плохие объекты (−1, кувырок, скорость ÷2), арки (присесть
или перепрыгнуть), большая арка на всю ширину дороги (сбить только в прыжке).

**Как закончить:**
- **Цель:** проехать **10 км** (столько же добавляет каждое «продолжение»).
- При достижении цели — **не сразу финал**: дорога очищается, **10 секунд**
  обратного отсчёта с текстом «ДЛЯ ПРОДОЛЖЕНИЯ — СДЕЛАЙТЕ ПРЫЖОК ВВЕРХ».
  Прыжок → цель сдвигается ещё на один сегмент, игра продолжается.
  **Таймер забега на паузе** на время этого вопроса.
- Без прыжка — **кат-сцена победы**: итоги забега, фото (если топ-3),
  таблицы рекордов **только по категориям, куда забег попал в топ-10**,
  финальный экран «ВЫ ПРОШЛИ ДО КОНЦА» + «ПОЗДРАВЛЯЕМ!!!» с конфетти и
  салютом (3 цикла), затем возврат в меню.
- Столкновения не завершают игру — только откатывают скорость.

**Физический жест (2 датчика на игрока, бинарные):**
- обе руки вниз → присесть
- одна вверх, другая вниз → полоса в сторону опущенной руки
- **взмах** (ритмичное движение обеими руками) → прыжок

**Датчики:** VL53L0X по I2C, VIN каждого на отдельный цифровой пин (см.
`hardware-wiring.md`).

**Клавиатура (симуляция):**
- Правый: `←→` полоса, `↑` прыжок, `↓` присед (`IJKL`: I/J/K/L)
- Левый: `AD` полоса, `W` прыжок, `S` присед
- **Меню:** WASD / IJKL — навигация; на строках «1/2 игрока» и «полосы» —
  **короткий «вниз»** сразу переходит дальше; **удержание «вниз» 5 сек** только
  на строке СТАРТ/ТРЕНИРОВКА — подтверждение (не Space/Enter)
- **F1** — справка; **Q** при открытой справке — выход
- **Выход из игры:** все активные игроки держат присед **5 сек молча + 5 сек
  с обратным отсчётом** (`DuckToExitController`), либо кнопка выхода на плате
  (когда будет)

**Имитатор датчиков (2×2 на игрока):**
```
Левый:  Q/A (левая рука), E/D (правая)
Правый: U/J, O/L
```
Частые нажатия обеих «верх»-клавиш = взмах → прыжок.

**Стартовое меню:**
1. **1 / 2 игрока** — превью второго жука на дороге
2. **Число полос** (1–3; вдвоём минимум 2)
3. **СТАРТ / ТРЕНИРОВКА** — подтверждение удержанием «вниз» 5 сек (на остальных
   строках «вниз» — обычный переход)

Контроллер определяется **автоматически** (датчики или джойстик по Serial);
если железа нет — «КОНТРОЛЛЕР НЕ ОБНАРУЖЕН», игра с клавиатуры.

**Тренировка:**
- Карусель схем трюков/жестов → экран практики
- **Выход:** все **активные** игроки держат присед вместе — **3 сек молча +
  5 сек обратного отсчёта** (1 игрок = только он; 2 игрока = оба)

**Железо (основная сборка):** одна Nano — `CombinedBoard.ino` (2× VL53L0X
игрок 1 + джойстик игрок 2), Unity — `JoystickSerial.cs`. Альтернатива:
отдельная плата только с 2 датчиками — `GestureSensors.ino`
(`G,<left>,<right>`). Подробно — [`hardware-wiring.md`](hardware-wiring.md).

**Микроконтроллер:** Arduino Nano (ATmega328P), см. `technical-details.md` §5.

**Открытые вопросы:** физическое крепление дальномеров; дебаунс порогов
(`DownThresholdMm = 150`, `UpThresholdMm = 300` в `GestureInput`).
